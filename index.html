What it is

Built to be useful.

Vodka Client is not meant to be only a PvP client. Building and utility are core parts of the project, especially for anarchy gameplay.

Primary focus

Building

Tools aimed at making large projects, repetitive placement, navigation, and general building work easier to manage.

Utility

Anarchy

General tools for exploration, travel, navigation, inventory management, and everyday server use.

Combat

PvP / Crystal PvP

Combat-oriented modules alongside the building and utility systems.

Movement

Travel

Movement and navigation features designed to make getting around easier.

Project direction

Clean and expandable

The client is actively being developed with more modules, better performance, improved compatibility, UI refinements, and additional Minecraft version support planned.

FAQ

Quick answers.

What Minecraft version is supported right now?

Vodka Client V1.0.0 currently supports Minecraft 1.21.11 on Fabric.

Will 1.21.4 through 1.21.10 be supported?

Yes. Those versions are planned next before development moves on to 26.1 and 26.2.

Does Vodka Client support NeoForge?

Not currently. Fabric is the supported loader today, with NeoForge planned as a future target.

Where should I download Vodka Client?
